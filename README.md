# Sistem Informasi Angkutan Pedesaan Jombang

## Deskripsi

Sistem Informasi Angkutan Pedesaan Jombang merupakan aplikasi berbasis
web yang menyediakan informasi mengenai angkutan pedesaan di Kabupaten
Jombang, meliputi rute, jadwal, tarif, titik pemberhentian, dan status
operasional.
